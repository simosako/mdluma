# Product Overview

updated_at: 2026-04-29

## 概要

MDLuma は、Markdown ファイルをすばやく安全に読むための軽量ビューアーです。主目的は編集ではなく閲覧であり、Markdown を HTML に変換して表示する単機能アプリとして設計します。

このプロジェクトでは、起動速度、省メモリ、実装の単純さを優先します。Windows 11/10 を最初の対象としつつ、将来の macOS / Linux 対応を妨げない構成を保ちます。

## コア能力

- Markdown を GitHub Flavored Markdown ベースで HTML に変換して表示する。
- 読み込み済みドキュメントと未読み込み状態を明確に分けた、読み取り専用の表示体験を提供する。
- 必須ランタイムやアセットが不足している場合は、起動前に診断可能なエラーとして停止する。
- HTML/CSS ベースの UI を使い、タイトルバーを含む最小限のビューアー操作を提供する。

## 主な利用シナリオ

- ローカルの Markdown ファイルを、ブラウザを開かずにすぐ確認したい。
- 配布しやすい Windows 向け Markdown ビューアーを必要としている。
- エディタとは分離した、軽量で読み取り専用のプレビュー体験がほしい。

## 価値

- ビューアーに必要な責務へ絞ることで、起動と動作を軽く保つ。
- Markdown 変換と UI 描画を分離し、表示品質と実装保守性を両立する。
- 失敗時は黙って壊れるのではなく、ユーザー向けメッセージと診断情報を分けて扱う。

## 境界

- 編集機能、保存機能、タブ管理のようなビューアー外の機能は、明確な必要性がない限り追加しない。
- 外部アプリケーション連携は、ビューアー体験を損なわず、実装を複雑にしない範囲でのみ検討する。
